# EmployeeDepartment.UI

Frontend application for the Employee & Department Management System built using **React**.  
This project connects with the ASP.NET Core Web API backend to perform employee and department management operations.

## Technologies Used

- React
- React Router DOM
- Axios
- Bootstrap / CSS
- ASP.NET Core Web API (Backend)
- SQL Server

---

## Features

### Department Management
- View all departments
- Add new departments
- Update department details
- Delete departments

### Employee Management
- View all employees
- Add new employees
- Edit employee details
- Delete employees
